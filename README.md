# LumeQuery

### AI-Powered Data Intelligence Platform

LumeQuery is an independent portfolio project exploring the integration of data analytics, artificial intelligence, and business intelligence.

The project aims to transform structured data into meaningful insights through analytical queries, natural-language interaction, and data visualization.

## Project Objectives

- Design and implement a relational database using PostgreSQL.
- Develop data processing and analytical workflows with Python.
- Explore natural-language interaction with structured data using Large Language Models (LLMs).
- Implement controlled SQL generation, validation, and execution.
- Transform analytical results into meaningful business insights.
- Explore workflow automation and interactive data visualization.

## Planned Features

- Relational database design and data modeling.
- Synthetic dataset generation.
- SQL-based business analytics.
- AI-powered natural-language data queries.
- Query validation and execution safeguards.
- Automated analytical workflows.
- Interactive dashboards and visualizations.

## Technology Stack

| Technology | Purpose |
|---|---|
| Python | Data processing and application development |
| PostgreSQL | Relational database management |
| SQL | Data querying and analytics |
| Pandas | Data manipulation and analysis |
| Gemini API | AI-powered natural-language interaction |
| Power BI | Business intelligence and visualization |
| n8n | Workflow automation |

## Project Architecture

The planned architecture connects relational data storage, Python-based processing, AI-assisted querying, workflow automation, and business intelligence visualization.
